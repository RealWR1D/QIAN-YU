# 素材与权利说明

千语 / QIAN YU 是非官方同人项目，与《明日方舟：终末地》的权利方不存在官方合作或背书关系。

项目使用的角色、名称与相关游戏内容，其权利归相应权利人所有。应用图标目前的来源署名为 **Bilibili @唐可可为什么是神**；来源署名不是使用授权，本项目尚未记录可核验的图标分发授权。

在扩大公开分发前，需要核对适用于分发地区的游戏同人规范，以及其是否覆盖角色陪伴应用；同时向画师确认图标是否允许用于应用、源码仓库与安装包。授权尚不明确时，应使用获得许可的替代素材，或先移除相关素材。

项目不以盈利为目的，但这不能自动免除第三方素材的授权要求。第三方图片和游戏素材不因进入源码仓库而变成可以任意使用的开源资源。仓库目前没有统一的开源许可证；公开可见不等于授予任意复制、修改和再分发的许可。后续确定代码许可证时，应明确排除第三方素材。

如权利人需要联系维护者，可通过仓库 Issue 提供作品来源、权利关系及具体诉求；请勿在公开 Issue 中提交个人敏感信息。

参考：[《中华人民共和国著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。
