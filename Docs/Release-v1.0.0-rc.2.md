# QIAN YU v1.0.0-rc.2 · 日常提醒与使用指南

## 更新内容

- 每日提醒按课表和睡眠自动化安排：午饭跟随上午下课时间，午后默认 13:45、仅在 14:00—15:00 有课时发送，新增默认 18:00 的傍晚提醒。
- 新增「睡眠已结束」和「准备睡觉」快捷指令动作。早安最迟在设定时间后一小时发送，晚安最迟在设定时间发送；应用内提供配置说明。
- 每日问候可使用已配置的 AI，结合天气预报、当天课程时长和傍晚剩余课程生成，检查正文重复，生成失败时使用可变的本地文案。
- 支持查找常用城市和区，也可主动获取当前位置。定位不可用或超过一天未更新时，回退到常用城市。
- 支持从 iPhone 文件或附件打开 `.ics` 导入预览，确认后才保存，并改善重复导入与文件选择恢复。
- 改进番茄钟状态恢复、后台倒计时和实时活动显示，调整小组件及相关界面。
- 集中管理显示文案，补充文案维护说明，以及详细使用指南的 Markdown 和独立 HTML 版本。

## 验证

本次 iOS（含小组件）和 macOS 的未签名 Release 构建通过。每日推送规则检查 38 项、每日文案检查 183 项，以及番茄钟、API 配置、ICS 导入和文案资源检查均通过。

此前已由用户在 iPhone 上确认测试通知、番茄钟及锁屏实时活动、重复日历同步、小组件和聊天记录保存正常。新增天气定位、AI 每日问候和睡眠自动化仍需进一步真机验收，故继续作为源码预发布。

## 使用说明

本次提供源码及使用文档，不提供可直接安装的签名 App 或 IPA。下载源码后通过 Xcode 编译；免费 Personal Team 的安装签名到期后，需要重新编译安装。

通知使用普通本地通知，遵循系统专注模式和通知设置。睡眠联动需要手动配置快捷指令；每日提醒预排未来 7 天，打开应用或执行睡眠动作会续排，系统后台刷新不保证执行。AI 聊天、连接测试和自动问候可能产生服务商费用。
