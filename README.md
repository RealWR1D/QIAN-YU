# QIAN YU

> 一款支持 iOS 和 macOS 的千语陪伴应用。icon：Bilibili@唐可可为什么是神

使用文档见：[千语使用文档](https://lorra.cloud/qianyu)

iPhone 免费自签与 Mac 下载包的说明见[安装与分发](Docs/安装与分发.md)。本项目为非官方同人应用，第三方素材的来源和授权状态见[素材与权利说明](Docs/素材与权利说明.md)。

维护与发布前检查见[维护与验证](Docs/维护与验证.md)。在项目根目录运行 `bash Scripts/check_project.sh`，可执行回归检查及 iOS、macOS Release 构建。

## 核心功能

### 1. 提醒上课 (课程表与上课提醒)
* **智能周期提醒**：根据周一至周日的课程排期自动提醒上课，支持自定义提前推送。
* **千语专属通知语录**：
  > *「管理员！下节是【电路与电子学】在【T4502】，还有 15 分钟！课本和笔带齐没？走走走，冲冲冲！」*
* **首页动态倒计时横幅**：主界面随时显示下一门课程的距离时间、地点及快速打气入口。
* **课程管理**：可以手动添加、停用或删除课程，也支持导入 `.ics` 课表并同步到系统日历。
  在 iOS 文件或附件的分享菜单中选择 **QIAN YU**，即可打开课程导入预览；选择课程并确认导入后保存到课表。也可继续使用应用内的文件选择器导入。

### 2. 每日陪伴推送
使用本地通知，根据课表和睡眠自动化安排问候：
* **清晨唤醒**：优先在退出睡眠模式时提醒，最迟在设定时间后一小时提醒。
* **午饭提醒**：上午最后一节课早于 11:00 结束时，11:30 提醒；11:00 或之后结束时，下课即提醒。没有上午课时使用设定时间。
* **午后防困（默认 13:45）**：仅在当天 14:00–15:00 有课时，提前提醒喝水、活动肩颈。
* **傍晚鼓励（默认 18:00）**：后面还有课时鼓励继续完成剩余课程；没有后续课程时提醒放松，全天无课时只作轻松问候。
* **深夜就寝**：优先在进入睡眠模式时提醒，最迟在设定时间提醒。早晚每天各一次，超过截止时间不再补发。
* **通知方式**：使用普通通知，声音、横幅和专注模式下的显示遵循系统设置。当前免费 Personal Team 不支持「即时通知」签名能力，因此保留普通通知以便直接编译安装。

每日文案优先由已配置的 AI 生成：早晨结合所选地点的天气预报，中午结合全天课程时长，傍晚结合提醒时刻之后的课程，就寝只说晚安。正文会检查重复，开场、表达和结尾也会变化；无 API、网络失败、无效或重复回复时使用可变的本地文案。提示词和本地语料集中放在 `EditorialContent.json` 的 `notification.ai.prompt` 和 `notification.variation.*` 中。

在推送设置页可开关 AI 问候、查找并选择常用城市和区，默认深圳市南山区；也可点击「使用当前位置」申请使用期间定位。拒绝、撤销定位或当前位置超过一天未更新时，使用常用城市。天气来自 [Open-Meteo](https://open-meteo.com/)，天气服务接收地点坐标，AI 接收天气概况、课程统计、称呼、角色设定和近期通知正文，不接收精确坐标、街道地址或聊天记录。自动生成沿用当前 API 与模型，并使用模型已支持的轻量思考档位，可能产生费用。

文案在打开应用或系统允许后台刷新时提前准备、缓存，通知到点不会临时请求 AI。天气使用对应日期的预报，缺少可靠数据时不提天气；系统不保证后台刷新执行，所以无法保证每条通知都是到点实时生成。

iOS 不会直接向应用提供睡眠专注模式的切换事件，需要在 iPhone「快捷指令 → 自动化」中配置两项个人自动化：
1. 选择「睡眠」专注模式的「关闭时」，添加千语的「睡眠已结束」动作，选择「立即运行」。
2. 选择「睡眠」专注模式的「开启时」，添加千语的「准备睡觉」动作，选择「立即运行」。
3. 在千语「每日推送与提醒」中开启「已配置睡眠自动化」。清晨动作在上午生效，晚安按当次就寝的截止时间判断，支持跨午夜；请保持两项自动化开启。

未启用睡眠自动化时，早晚仍按设定时间提醒。每日提醒预排未来 7 天，打开应用或执行睡眠动作会续排，系统后台刷新也会尝试续排；若长期不打开应用且自动化未运行，后续每日提醒可能中断。页面保留测试通知按钮，点击后约 3 秒可验证通知效果。

### 3. 闲聊与陪伴 
* **角色设定**：默认使用原版完整人设，保留人物经历、关系、原声例子与事实边界，仅适配应用对话身份及实际可用能力。时间、课程只作为事实背景注入。可在「设置 → 关于应用 → 角色人设」修改并保存；从下一条 AI 对话起生效，离线固定台词仍使用内置文案。此前保存过自定义人设的用户，可点击「恢复默认」并保存以切换到完整版本。
* **聊天支持**：
  * **云端 LLM 流式输出**：支持 OpenAI 兼容协议的 API Key，输出伴随触觉反馈。设置页可读取当前服务端返回的模型列表，也可手动填写模型 ID；每个服务商分别保存地址、模型、思考设置及钥匙串中的密钥。
  * **配置验证**：设置页会区分「已保存」和「连接测试通过」。手动点击「测试当前配置」会向所选模型发送一条短请求，可能产生少量 API 费用。
  > 没有可用的 API 配置时，应用会使用内置语料回复，能力相对有限；本机 Ollama 兼容接口可不填 API Key。
* **快捷胶囊话题**：
  * `💆 按按肩颈` · `🏫 下节什么课？` · `📖 讲讲大院故事` · `🗡️ 当破即破！` · `🧋 碰碰杯杯`

### 4. macOS 适配：MenuBarExtra 菜单栏常驻
* 在 macOS 顶部菜单栏常驻千语图标 “QIAN YU“。
* 轻点即可滑出浮窗：查看千语当前随行状态、下一门课倒计时、直接在状态栏进行迷你闲聊，无需切换工作流。

### 5. 专注与小组件
* 番茄钟支持专注和休息计时；iPhone 上可通过实时活动查看进度。
* 桌面和锁屏小组件会显示当前教学周与接下来的课程。

## 🚀 如何运行项目

1. **打开工程**：
   * 在 Finder 中找到并双击打开 `QIAN YU.xcodeproj`；
   * 或在终端执行：`open "QIAN YU.xcodeproj"`。

2. **选择运行平台**：
   * **运行在 Mac**：在 Xcode 顶部目标设备选择 **My Mac**，按下 `Cmd + R`；
   * **运行在 iPhone / iPad 模拟器**：在目标设备选择一台可用的模拟器，按下 `Cmd + R`。

3. **初次启动**：
   * 在设置页授予通知权限后，才能收到每日问候与上课提醒。
   * 在「每日推送」页面，点击“立即发送一条测试通知”，3 秒内即可看到千语发来的测试横幅。
